Sambla Chat — Ghid de integrare

Widget-ul merge pe orice site. Pe WordPress + WooCommerce, pluginul oficial face totul automat. Pe restul site-urilor (Shopify, Magento, SPA, landing pages), fie lași detectarea automată pe URL, fie trimiți context manual cu un singur apel JS.

1. Integrare minimă — orice site

<script
  src="https://sambla.ro/widget/sambla-chat.js"
  data-channel-id="YOUR_CHANNEL_ID"
  data-color="#991b1b"
  async defer></script>

Atât. Widget-ul se încarcă, detectează tipul paginii din URL (vezi mai jos), iar utilizatorul poate conversa liber și vede chips contextuale dacă pagina se potrivește unui tipar cunoscut.

2. Detectare automată pe URL

Fără niciun cod suplimentar, widget-ul clasifică pagina curentă în una din aceste categorii, după URL:

Tip paginăModele de URL (primul match câștigă)
cart/cart/, /cos/, /checkout/, /panier/, /order/, /commande/, /warenkorb/
product/products/ (Shopify), /product/ (WC, Magento, PrestaShop), /produs/, /p/…
category/collections/ (Shopify), /product-category/ (WC), /catalog/category/ (Magento), /category/, /categorie/, /shop/, /magazin/, /catalog/
booking/rezervare, /booking, /programare, /appointments/, /book-now, /schedule/
hospitality/hotel, /camere, /restaurant, /masa, /reservations/, /rooms/, /dining/
home/
generalorice altceva
Pentru majoritatea site-urilor Shopify, WooCommerce, Magento sau PrestaShop, detectarea automată merge fără nicio configurare.

3. Trimitere context manual (recomandat pentru SPA / custom)

Dacă site-ul tău folosește URL-uri custom, framework SPA (React, Vue, Angular) sau vrei să oferi bot-ului detalii despre produsul curent, folosește API-ul window.sambla.setContext(...):

<script>
window.sambla = window.sambla || {};
// Pe pagina de produs, înainte de script-ul widget-ului:
window.sambla.setContext = window.sambla.setContext || function(ctx){
  if (ctx.page_type) window.samblaPageType = ctx.page_type;
  if ('product' in ctx) window.samblaProductContext = ctx.product;
  if ('cart' in ctx)    window.samblaCartContext    = ctx.cart;
};
window.sambla.setContext({
  page_type: 'product',
  product: {
    product_id: 42,
    name: 'Bluza roșie XL',
    price: '99.00',
    currency: 'RON',
    in_stock: true,
    categories: ['Haine', 'Bluze']
  }
});
</script>

După ce widget-ul încarcă, window.sambla.setContext e disponibil direct — nu mai ai nevoie de stub-ul inline.

SPA — la schimbarea rutei

// De fiecare dată când utilizatorul navighează între rute:
router.afterEach((to) => {
  if (to.meta.productId) {
    window.sambla.setContext({
      page_type: 'product',
      product: to.meta.productContext
    });
  } else if (to.path === '/cart') {
    window.sambla.setContext({ page_type: 'cart' });
  } else {
    window.sambla.clearContext();
  }
});

Dacă utilizatorul are deja fereastra de chat deschisă când navighează, widget-ul ascultă un CustomEvent sambla:context-changed și reîmprospătează chips-urile automat — nu e nevoie să refaci nimic.

4. Formele contextelor

samblaProductContext

{
  product_id: 42,          // required — ID numeric
  name:       'Bluza roșie XL',
  price:      '99.00',
  currency:   'RON',       // ISO 4217
  categories: ['Haine', 'Bluze'],   // listă scurtă
  in_stock:   true,        // opțional
  permalink:  'https://site.ro/bluza-rosie-xl'  // opțional
}

samblaCartContext

{
  items_count: 2,
  total:       '340 lei',
  currency:    'RON',
  items: [
    { product_id: 42, name: 'Bluza roșie XL', qty: 1 },
    { product_id: 17, name: 'Pantofi eleganți 42', qty: 1 }
  ]
}

samblaPageType — valori valide

product, category, cart, booking, hospitality, home, general

5. Degradare gracefulă

Widget-ul nu se rupe niciodată dacă contextul lipsește — cade pe detectare URL, apoi pe general. Freeform chat și răspunsul AI merg identic în toate cazurile.

Ce pierzi când contextul lipsește:

  • Chips-uri specifice paginii (produs / coș / rezervare) — rămâi cu chips-uri de nișă generice
  • Bot-ul nu știe numele produsului curent în context la primul mesaj
  • Bot-ul nu vede conținutul coșului

6. Depanare rapidă

SimptomCauza probabilă
Chips nu aparCanal inactiv sau nișa botului nu are configurație contextuală în config/widget_contexts.php
Chips generice pe pagina de produsURL-ul nu face match cu regex-ul; folosește window.sambla.setContext({page_type:'product', ...})
Widget-ul nu se încarcăVerifică data-channel-id și că domeniul e permis în setările canalului (sambla.ro → Canale → Web chatbot)
Pentru WooCommerce: folosește pluginul oficial Sambla ↔ WooCommerce (versiune 2.1+) — detectează automat produs/coș/categorie și injectează contextul, fără cod manual.
